# Блок 2. Вариант 7: аренда туристического снаряжения

- `src/` — часть 1: классы `Tent`, `SleepingBag`, `CampingStore` (перегрузка, цепочка конструкторов, static).
- `part2/src/` — часть 2: абстрактный `Tent`, наследники `UserTent` и `CorporateTent`,
  интерфейс `NotificationService` с реализациями `EmailNotification` и `SmsNotification`,
  `CampingStore` с внедрением зависимости через конструктор.
- `part2/UML.md` — UML-диаграмма классов части 2.

Запуск части 2:

```
cd part2/src
javac *.java
java CampingStore
```
